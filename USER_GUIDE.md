# 🤖 Chatrix — Инструкция по использованию

Чатрикс — это не просто генератор демотиваторов, а умный (и иногда дерзкий) собеседник, который учится на стиле общения вашего чата.

## 💬 Как общаться с ботом

### 1. Инлайн-мемы (НОВОЕ!)
Теперь вы можете создавать мемы с любым текстом в любом чате:
1. Введите в поле ввода сообщения: `@имя_вашего_бота ваш текст`
2. Появится галерея шаблонов из папки `memes/`.
3. Выберите понравившийся шаблон.
4. Бот автоматически создаст мем с вашим текстом (сверху, в стиле Impact) и отправит его.
*Примечание: Если превью не отображаются, администратору нужно выполнить команду `S index`.*

### 2. Прямое обращение
Стандартные ответы ИИ на упоминание через `@имя_вашего_бота` временно отключены в пользу инлайн-режима мемов. Бот продолжает отвечать в личных сообщениях и спонтанно в группах (согласно настройке "Лени").

### 2. Спонтанные ответы
В зависимости от настройки **"Лени"** (изменяется админами через `S c`), бот может сам вступать в диалог:
- Комментировать ваши сообщения.
- Присылать смешные гифки или фото из истории чата.
- Вставлять "умные" замечания по теме обсуждения.
- Бот берет фразы и стиль из истории вашего чата.

### 3. Реакция на медиа
Бот обожает картинки и видео. Команды `S g d` (демотиватор) работают с:
- **Фото**: Обычные картинки.
- **Видео и Кружочки**: Превращаются в зацикленные видео-демотиваторы (как гифки).
- **GIF**: Анимированные мемы.

### 4. Гостевой режим (НОВОЕ!)
Теперь вы можете вызвать Чатрикса в **любом** чате (в личке с друзьями, в других группах), даже если бота там нет. Просто напишите в сообщении `@имя_вашего_бота`.
- Бот увидит ваше сообщение и ответит на него.
- Идеально для быстрых вопросов или когда нужно "призвать" ИИ в разговор.

## 🎮 Основные команды

| Команда | Что делает |
|---|---|
| `S g` | Открыть интерактивную панель генерации. |
| `S g d` | Сделать демотиватор из реплая на фото/видео или случайного медиа. |
| `S g d ai` | Демотиватор с "умной" подписью (ИИ анализирует ситуацию в чате). |
| `S g m` | Создать мем (бот берет шаблон и наполняет его цитатами из чата). |
| `S g a` | Сгенерировать анекдот про участников чата. |
| `S g l` | Написать длинный связный текст на основе истории переписки. |
| `S top` | Показать 5 лучших демотиваторов (по лайкам). |
| `S stats` | Показать твою статистику лайков и оценок. |
| `S game quiz` | Запустить викторину по истории вашего чата. |
| `S c` | Меню настроек (Интеллект, Лень, Доступ). Только для админов. |
| `S h` | Вызвать справку в чате. |

---

## ⚙️ Советы для админов (`S c`)
- **Интеллект**: По умолчанию стоит "Максимальный". В этом режиме бот действительно "умный". Режим "Классический" делает бота более простым (только цитаты).
- **Лень**: Чем ниже процент, тем активнее бот. На **10%** бот будет участвовать почти в каждом обсуждении.
