# AGENTS.md — инструкции для AI-ассистентов

## Проект
Chatrix — Telegram бот на Python (aiogram 3.x) с генерацией контента через OpenRouter/Groq/Google AI API.

## Архитектура
- `chatrix.py` — точка входа, регистрация роутеров, middleware, heartbeat
- `handlers/` — хэндлеры команд (generate, settings, misc, inline, mafia, business)
- `utils/` — утилиты (ai, access, cooldown, demotivator, meme_gen, quiz, likes и др.)
- `config.py` — токены из env, списки моделей, настройки доступов/кулдаунов

## Правила работы
1. **Не коммитить токены и ключи** — все ключи в `config.py` читаются из `os.getenv()`. Никогда не выкладывай реальные ключи.
2. **Не создавать файлы без необходимости** — редактировать существующие файлы, а не писать новые.
3. **Не добавлять комментарии в код** если не попросили.
4. **Стиль кода** — Python, f-строки, докстринги на русском, логи через `logging.getLogger(__name__)`.
5. **Импорты** — сначала стандартные, потом aiogram, потом локальные (from utils..., from handlers..., from config).
6. **Роутеры aiogram** — каждый handler-файл создаёт `router = Router()`, который импортируется в `chatrix.py`.
7. **Middleware** только в `chatrix.py` через `outer_middleware()`.

## Запуск
```bash
python chatrix.py
```

## Тестирование
Юзать вручную через Telegram. Отдельного тестового фреймворка нет.

## Верификация после изменений
После любых правок кода — запускать проверку синтаксиса:
```bash
python -c "import py_compile; py_compile.compile('chatrix.py', doraise=True); print('OK')"
```
Либо проверить все изменённые файлы по отдельности.

## Структура команд
- `S g` — генерация текста
- `S g w` — случайное слово
- `S g p` — опрос/викторина
- `S g d` — демотиватор
- `S g d ai` — демотиватор с AI-подписью
- `S g d g <описание>` — демотиватор из сгенерированной картинки
- `S g m` — мем
- `S g a` — анекдот
- `S c` — настройки чата (админы)
- `S h` — помощь
- `/mafia`, `/join`, `/ready`, `/startmafia`, `/settings` — мафия

## Что нельзя делать
- Не менять режимы доступа без явной просьбы
- Не отключать кулдауны без явной просьбы
- Не добавлять внешние зависимости без явной просьбы
