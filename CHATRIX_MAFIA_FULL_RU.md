# CHATRIX MAFIA

## ПОЛНАЯ ТЕХНИЧЕСКАЯ ДОКУМЕНТАЦИЯ

Версия: 2.1

------------------------------------------------------------------------

# 1. ЦЕЛЬ ПРОЕКТА

Создать модуль Telegram-игры «Мафия» для Chatrix.

Требования:
- Полная автономность от истории чата.
- Поддержка ролей: Мирный, Мафия, Доктор, Комиссар.
- Атомарность всех операций (защита от гонок данных).
- Сохранение состояния при перезагрузке бота.
- Гибкая система настроек для каждого чата.

---

# 2. АРХИТЕКТУРА И СТРУКТУРА МОДУЛЯ (mafia.py)

Модуль построен на базе асинхронного управления состоянием (State Machine) с использованием блокировок (`asyncio.Lock`) для обеспечения атомарности операций при многопользовательском доступе.

## Разделение кода по блокам (строки):

| Диапазон | Название блока | Описание |
| :--- | :--- | :--- |
| **1–150** | Imports & Config | Импорты, определение констант состояний фаз и ролей. |
| **151–250** | Locking & I/O | Управление `asyncio.Lock` для каждого чата, файловые операции (`_get_game_unlocked`, `_put_game_unlocked`). |
| **251–450** | Timers & Worker | Логика работы таймеров (`_timer_worker`), планирование и отмена фаз. |
| **451–650** | Lobby & Player Logic | Управление лобби, вход/выход, готовность игроков. |
| **651–900** | Role Assignment | Распределение ролей, логика ночных действий (килл, хил, проверка), AFK-логика. |
| **901–1100** | Phase Transitions | Логика смены дня и ночи, переключение фаз (`_process_night`, `_start_discussion`). |
| **1101–1250** | Voting System | Обработка голосования (`_process_vote`), определение исключенных. |
| **1251–1400** | End Game & Demo | Логика окончания игры, демо-режим. |
| **1401–1750** | Telegram Handlers | Все публичные хэндлеры (`/mafia`, `/join`, `/vote`, колбэки настроек). |

---

# 3. КРИТИЧЕСКИЕ АРХИТЕКТУРНЫЕ ПРИНЦИПЫ

1.  **Атомарность**: Все функции, меняющие состояние игры (`phase`, `players`, `votes`), вызываются внутри `async with _get_chat_lock(chat_id):`.
2.  **Internal-методы**: Функции с суффиксом `_internal` (напр., `_process_night_internal`) предназначены для вызова **только** из-под уже захваченного лока, что предотвращает дедлоки.
3.  **Безопасный I/O**: Использование `_unlocked` методов внутри операций сохранения предотвращает рекурсивную блокировку.
4.  **Безопасность**: Все никнеймы игроков в HTML-сообщениях экранируются через `escape()` или `_mention()`.

---

# 4. ЖИЗНЕННЫЙ ЦИКЛ ИГРЫ

1. **LOBBY**: Ожидание готовности игроков.
2. **ROLE_DISTRIBUTION**: Раздача ролей.
3. **PHASE_NIGHT**: Активные роли делают действия.
4. **PHASE_DISCUSSION**: Обсуждение (чат открыт).
5. **PHASE_VOTING**: Голосование.
6. **GAME_END**: Подведение итогов.

1. Создание игры
В группе пишешь:

/mafia
Бот создаёт лобби мафии.

В лобби видно:

сколько игроков уже вошло;
сколько нужно минимум;
сколько максимум;
кто готов;
кто ведущий лобби;
сколько времени осталось до автоудаления лобби.
Кнопки:

➕ Войти в игру
✅ Я готов
▶ Начать игру
👥 Игроки
➖ Выйти
❌ Закрыть лобби
Команда-аналог:

/join
/ready
/startmafia
/leave
/cancelmafia
/players
2. Лобби
Игрок нажимает Войти в игру или пишет:

/join
После этого он должен нажать Я готов или написать:

/ready
Создатель лобби помечается как ведущий. Если он выйдет, бот может передать владельца самому раннему вошедшему игроку, если это включено в настройках.

По умолчанию:

минимум игроков: 4;
максимум игроков: 12;
лобби закрывается через 10 минут, если игру не начали.
3. Старт игры
Ведущий или админ нажимает Начать игру или пишет:

/startmafia
Перед стартом бот проверяет:

достаточно ли игроков;
все ли нажали готовность;
может ли бот написать каждому игроку в личку.
Если у кого-то закрыты ЛС с ботом, игра не начнётся. Бот покажет список этих игроков и попросит открыть личные сообщения с ботом.

4. Раздача ролей
Если проверки прошли, бот раздаёт роли в личные сообщения.

Роли:

Мирный житель — ищет мафию днём, ночных действий нет.
Мафия — ночью выбирает жертву.
Доктор — ночью выбирает, кого лечить.
Комиссар — ночью проверяет игрока и узнаёт: мафия он или нет.
Распределение:

мафия: примерно 1/4 игроков, минимум 1;
доктор появляется от 5 игроков;
комиссар появляется от 6 игроков;
остальные становятся мирными.
5. Ночь
После раздачи ролей начинается ночь.

В группе бот пишет, что город засыпает. Активным ролям в ЛС приходят кнопки.

Мафия получает выбор жертвы. Если мафий несколько:

каждый мафиози голосует за цель;
выбирается цель с большинством;
при ничьей цель выбирается случайно среди лидеров.
Доктор выбирает, кого лечить. По умолчанию доктор может лечить себя, но не два раза подряд.

Комиссар выбирает, кого проверить. Ответ приходит только ему:

МАФИЯ
НЕ МАФИЯ
Можно также использовать команды:

/kill имя
/heal имя
/check имя
/skip
По умолчанию ночь длится 45 секунд. Если игрок не сделал действие, оно пропускается.

6. Утро
Когда все активные роли сходили или вышло время, бот обрабатывает ночь.

Возможные итоги:

игрок погиб;
доктор спас жертву;
никто не погиб.
Если включена настройка “показывать роль после смерти”, бот покажет роль погибшего.

После утра бот проверяет победу. Если победителя ещё нет, начинается обсуждение.

7. Обсуждение
Бот пишет в группу:

началось обсуждение;
сколько времени есть;
что бот не подсказывает и не анализирует игроков.
По умолчанию обсуждение длится 90 секунд.

Бот специально не помогает игрокам искать мафию, потому что по ТЗ он не должен давать подсказки.

8. Голосование
После обсуждения начинается голосование.

Бот отправляет кнопки со списком живых игроков. Игрок выбирает, кого исключить.

Также можно командой:

/vote имя
Можно воздержаться кнопкой или командой:

/skip
По умолчанию голосование длится 30 секунд.

Игрок может изменить голос. По умолчанию лимит — 2 смены голоса.

Если включено анонимное голосование, бот не раскрывает подробный расклад. Если выключено, бот показывает итоги по голосам.

Если ничья — никто не исключается.

9. Исключение
Если один игрок получил больше всех голосов, он выбывает.

Если включено “показывать роль после смерти”, бот покажет его роль.

После голосования бот снова проверяет победу:

если победитель есть — игра заканчивается;
если нет — начинается новая ночь.
10. Условия победы
Мирные побеждают, если вся мафия выбыла.

Мафия побеждает, если количество мафии стало больше или равно количеству остальных живых игроков.

Например:

1 мафия и 1 мирный — победа мафии;
2 мафии и 2 мирных — победа мафии;
0 мафии — победа мирных.
11. AFK-система
Если включена AFK-защита, бот считает пропуски.

По умолчанию лимит — 3 пропуска.

Пропуски могут копиться, если игрок:

не сделал ночное действие;
не проголосовал.
Когда лимит достигнут, игрок исключается.

12. Настройки
Открываются командой:

/settings
Доступны владельцу игры или админу.

Настраивается:

минимум игроков;
максимум игроков;
длительность ночи;
длительность обсуждения;
длительность голосования;
время жизни лобби;
AFK-защита;
лимит AFK;
показывать ли роль после смерти;
могут ли мёртвые писать;
может ли доктор лечить себя;
лимит смены голоса;
передача владельца лобби;
повторная отправка роли через /role;
анонимное голосование;
автопропуск ночью.
Настройки сохраняются в файл:

data/mafia_games.json
То есть они не должны пропадать между партиями.

13. Восстановление после перезапуска
Игра сохраняется в mafia_games.json.

Сохраняется:

фаза игры;
игроки;
роли;
живые и мёртвые;
голоса;
ночные действия;
настройки;
таймер текущей фазы.
При запуске бота модуль мафии смотрит активные игры и восстанавливает таймеры для:

лобби;
ночи;
обсуждения;
голосования.
