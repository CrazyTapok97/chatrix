## 🏗 Архитектура проекта

Chatrix — единственный активный бот проекта (предыдущий бот, CrazyBot на Telethon, отошёл от дел и не используется).

- **Библиотека**: `aiogram` (не Telethon) — работает через обычный `BOT_TOKEN`, полученный от @BotFather. Нет пользовательской сессии, нет проблем с протуханием авторизации.
- **Точка входа**: `chatrix.py`
- **Диспетчер**: `aiogram.Dispatcher` с `MemoryStorage` для FSM.

### Структура роутеров (порядок регистрации важен!)
Роутеры регистрируются в `chatrix.py` → `main()` в следующем порядке:
1. `handlers/settings.py` (`settings_router`)
2. `handlers/native_features.py` (`native_router`)
3. `handlers/generate.py` (`gen_router`)
4. `handlers/inline.py` (`inline_router`)
5. `handlers/mafia.py` (`mafia_router`)
6. `handlers/business.py` (`business_router`)
7. `handlers/misc.py` (`misc_router`)

### Конфигурация
- `config.py` — хранит токены (`BOT_TOKEN`, API-ключи ИИ-провайдеров, читаемые из окружения), настройки кулдаунов, доступов (`ACCESS_MODES`), пути к файлам данных и конфигурацию автоматического контента (списки моделей).

## 📡 Поддерживаемые типы обновлений (Telegram Updates)

Бот явно запрашивает через `allowed_updates` в `dp.start_polling(...)`:
- `message`, `callback_query`, `inline_query`, `chosen_inline_result`
- `business_connection`, `business_message`, `edited_business_message`, `deleted_business_messages`

**Важно**: явное перечисление `business_*` типов означает, что Chatrix спроектирован с расчётом на поддержку **Chat Automation**. За обработку этих апдейтов отвечает `handlers/business.py`.

---

## 🩺 Мониторинг и отказоустойчивость

- **`heartbeat_loop(bot)`**: раз в 60 секунд записывает `data/heartbeat.json`, проверяет связь `bot.get_me()`.
- **`models_update_loop()`**: обновляет кэш моделей ИИ раз в 24 часа.
- **Логирование**: стандартный `logging`.

## 📁 Структура папок и модулей .py

### Корень проекта
- `chatrix.py` — точка входа, инициализация бота, диспетчера и запуск heartbeat.
- `config.py` — файл конфигурации с ключами и настройками.

### `handlers/` — Обработчики команд и сообщений
- `business.py` — Chat Automation / business-сообщения (обработка бизнес-подключений и сообщений).
- `generate.py` — генерация контента через AI (текст, картинки, опросы, демотиваторы, мемы, анекдоты, `S g d g`, генерация картинок через Magic Hour SDK + Pollinations.ai фолбэк).
- `inline.py` — inline-режим бота.
- `mafia.py` — логика игры в мафию.
- `misc.py` — прочие вспомогательные команды и обработчики.
- `native_features.py` — нативные функции бота.
- `settings.py` — настройки бота и чатов (команда настройки).

### `utils/` — Утилиты и бизнес-логика
- `access.py` — проверка прав доступа пользователей к функциям.
- `ai.py` — основная логика взаимодействия с внешними AI API (OpenRouter, Groq, Google AI). `gen_smart_reply` — не техподдержка, а участник чата. `BOT_KNOWLEDGE` минимальный.
- `ai_config.py` — конфигурационные данные и промпты для AI.
- `ai_updater.py` — логика обновления кэша доступных моделей ИИ.
- `auto_content.py` — автоматическая генерация контента в чатах.
- `business_state.py` — управление состояниями для бизнес-аккаунтов.
- `challenges.py` — система испытаний/челленджей.
- `chat_style.py` — утилиты для стилизации текста и оформления ответов.
- `cooldown.py` — управление ограничениями частоты использования (кулдауны).
- `demotivator.py` — логика генерации картинок-демотиваторов.
- `history.py` — управление историей сообщений для контекста AI. `format_history(shuffle_past, recent)` — последние `recent` сообщений хронологически, остальные перемешаны. `add_message()` сохраняет `reply_to_username`.
- `likes.py` — система реакций и лайков.
- `meme_gen.py` — логика генерации мемов.
- `meme_storage.py` — работа с шаблонами мемов и их хранилищем.
- `native_features.py` — вспомогательные нативные утилиты: `generate_image(image_desc)` — Magic Hour SDK (основной) → Pollinations.ai (фолбэк).
- `quiz.py` — логика проведения опросов и викторин.
- `settings_store.py` — хранение и загрузка настроек чатов из JSON-файла.
- `user_stats.py` — сбор и работа со статистикой пользователей.
- `name_cache.py` — кэш имён пользователей и транслитерация.
- `intents.py` — определение намерений (погода/время/поиск) и получение погоды.
- `reactions.py` — AI-выбор реакции-эмодзи на сообщение.
- `antispam.py` — защита от спама (burst limit, кулдауны, игнор).
- `backups.py` — создание zip-бэкапов проекта (ручные `/backup`, авто еженедельно в `data/backups/` + ежемесячно админу в Telegram).

### `data/` — Данные
- `heartbeat.json` — файл "пульса" для мониторинга.
- `chat_settings.json` — файл настроек чатов (путь из `config.py`).
